# 言葉の規律 — 文例と禁じ語

## 身分の札(右上・各画面)
- 「身分: <file> <key>(L1)・<図の種類>は説明用・判定は無い」
- 「記述だけ・凍結に無い」(凍結した述語に無い集計を見せるとき)
- 「見せるだけ・まとめの数は出さない」(並べて見せる状態)

## 限定の行(枠の下・章の全画面)
**下の文例は雛形。貼る前に、その画面の data に当てはまるかを確かめる**(行ごとの位置・帯・n を data から)。当てはまらない行が混ざる章では、札を行ごとに分ける。
- 「位置はすべて lens の fit 域(<N>)の外・provisional」
- 「記述だけ: 差は同じ計器の誤差帯(<W>)より小さい」
- 「<裁定で並置に留めたもの> とは同定しない(測っただけ)」
- 「<読んでいない側> は読んでいない」
- 「一つの model・一つの計器・<n> 行・違う場面は <k> つ」

## 言えない(台帳・明言する)
平叙文・14 px 以上・× 印で並べる。例:
- 「機構(写し取り・特定の head)は言わない」
- 「<ある組> が lens の 1 位に座ったことが、結論を決めた、とは言わない」
- 「並べた絵から、分かれ道で何が結論を決めたかは言わない」
- 「1 位の語は分からない(data に無い)」
- 「同じ seed の二行を独立な 2 例として数えない」

## 読み(L3)の札
「読み(L3)・実行層 ・<依頼者>が差し替える」— 依頼者の決め台詞の場所を作り手が埋めない。言い回しを提案するときは札を付ける。

## 書かない語・形
- 心の語: 考えた・迷った・気づいた・知っていた・本当は分かっていた・選び間違えた。
- 誇張: AI の心が見えた・嘘を見抜く・脳の中が見えた。
- 潰した値: 沈んだ・抑えられた・消えた(→「<上限> 位より下(潰した値・描き分けない)」)。
- eligible でない帯の null: 無い・現れない(→「この帯は監査を通っていない」)。
- 一例から: 〜だけ・いつも。
- 重みと内部状態の取り違え: 板に積まれているのは各層を通る内部状態(残差)であって重みではない、と札に書く。

## 語の衝突
- 内部名(例: 研究室の内輪の呼び名)と公開の語(例: seat / attractor state)が同じ物を指すか違う物を指すかを、図の中で解く(「<内部名> = ここ」「<別の物>(<内部名> とは別)」)。
- 稿の初出で意味を付ける語(例: closure / salient / oracle)は稿の glossary に従う。
