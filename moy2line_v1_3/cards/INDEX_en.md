# INDEX (English) — the moy-2 "reflection tool" line: cards olm113 … olm127 and the frontier controls prf4 / prf5

This folder holds the frozen originals of a line of pre-registered measurements run between 2026-11-02 and 2026-11-04. Each measurement is a pair of cards. A **PREREG** is the frozen promise written before the run: the instruments (regex / predicate read-outs, versioned), the gates, the questions with their verdict bands and predicted probabilities, what the run was set up to see, and what it does not claim. A **RESULT** is the read-out written after the run: gate values, verdicts (band names), descriptive counts, verbatim rows, the main session's readings marked as readings, and — where an error was found later — **corrections appended at the end without rewriting the body**. The originals are in Japanese and are kept exactly as frozen (their md5 values are listed in `SOURCES.tsv` and were re-checked against the files in this folder when this index was written: 37 / 37 match).

**This index is a guide, not a translation.** Nothing below is a translation of a card's body. The one-line English questions in Table 1 are paraphrases written for this index; the numbers, gate values, band names and md5 prefixes are copied from the cards' own §1–§3 tables, from the RECORD §2 table, and from `SOURCES.tsv`. Band names are given in English with the Japanese band word in parentheses so that the reader can find the row in the card's §2 table. Where a card carries an appended correction, Table 1 gives the corrected value and says "corrected (see 訂正 n)". Where two places disagree, both are written and each is cited. Readers who need the full argument should read the Japanese card; readers who need only the shape of the line can stop at Tables 1–2 and the "what is not claimed" section.

Terms that are not translated (先生, 主 session, 腕, 札, 帯, 関門, 計器, 証明の欄, 線対称, zebrashark, olmNNN, prfN) are glossed in the last section.

## Reading glosses

Terms left as written in the cards.

- **先生** — the principal investigator (the assistant's own address for its principal, left as written). "The PI" in this index.
- **主 session** — the main session: the Claude Code session that wrote the cards; sub-agents are named by role (cold judge, second reader, maker).
- **腕** — arm: one prompt condition (e.g. "formula only"), 60 rows in the generated cards.
- **札** — card: one PREREG + RESULT pair, named olmNNN or prfN.
- **帯** — band: the pre-registered verdict bands of a question (e.g. 上がる / 変わらない / 下がる / 間 = rises / unchanged / falls / between; 戻る / 残る = returns / remains; 直った / 直らない = fixed / not fixed; 通る / 通らない = passes / does not pass; 追う / 追わない = follows / does not follow; 続ける / 続けない = continues / does not continue; 当たり / 外れ = hit / miss).
- **関門** — gate: a condition the read-out must pass before a question is read (G0 md5 and calibration; G1 parsed-row rate or negative control; G2 status rate, descriptive side).
- **計器** — instrument: a regex / predicate read-out applied to the frozen text, versioned v2 … v6 (v3 = olm118, v4 = olm121, v5 = olm123, v6 = olm126); "hq" is the shared status / proof / route instrument of olm112–113 and prf4–5. 較正 = calibration (positive examples the instrument must pass before it runs); 陰性統制 = negative control (the 20 frontier proofs of prf5, expected to score 0).
- **証明の欄** — the proof field: the "proof" string in the JSON the model was asked to add (as opposed to 本文 = the body, the free text written before the JSON).
- **線対称** — line symmetry: the premise "Tc and Th are symmetric with respect to the line O1O2", false in the general figure (unequal radii), true only when the radii are equal; LN_a = proofs asserting it (instrument v3), LN6_a = the v6 variant. 点対称 = point symmetry about O3 (PT_a). 外接線の印 = outer-tangent markers (OUTER_a: tangent ∥ O1O2, O1O2 ⊥ tangent, O1O2 is the perpendicular bisector — properties of the outer common tangents written onto the inner one).
- **zebrashark** — the lab's build host (an M2 Ultra), where the generated cards and the read-outs were run.
- **olmNNN** — a card run on OLMo-3 32B base (OLMo-3-1125-32B); **prfN** — a frontier control run through `claude -p` (prf4 / prf5 = Opus 5.5 / Fable 5.1, effort xhigh).

Identifiers used in the tables above.

- **moy-2** — the question: two disjoint circles c (centre O2, radius 7.4607) and h1 (centre O1, radius 3.6869) with an inner common tangent l1 touching at Tc (on c) and Th (on h1); O3 = midpoint of O1O2; state one relation that always holds among {Tc, Th, O3}, as JSON (conjecture / status / proof). **apex** = the target relation |O3Tc| = |O3Th| (true). **MIDO3** = the false attractor class (Tc, O3, Th collinear / O3 = midpoint of TcTh; true only for equal radii). **EQ** = the equidistance class (= apex, true; see the olm125 correction). OTHER / NONE = other / no parsable JSON.
- **M2 / M2A / M2B** — the prompt variants: M2 = the public prompt with "write your reasoning first"; M2A = M2 + the status / proof appendix (olm113's tool-less text, md5 56182280…); M2B = JSON-only with proof and status as fields (prf5, olm116). **TOOL_D / TOOL / TOOL_U** — the Tool sections: formula only (olm122 / 124), formula + declaration (olm119), formula + instruction (olm125 / 127); see `PROMPT_PROVENANCE.md`.
- **REFL_CALC** — a body row that computed the reflection numerically (olm119's instrument). **REJ6** — a row that computed the reflection and wrote "not the same / is not Th / ≠ / doesn't match" (v6). **b2_j07 type** — a row that rejected numerically and still wrote line symmetry in the proof field (REJ6 ∧ LN6_a; named after olm124 b2_j07). **tool_named** — the row names the tool / formula. **SUPP_LN / REJ** — descriptive aids of olm125 (v3-missed direct-object forms; the pre-v6 rejection predicate).
- **G1 history** — 0.80 for olm113–olm122; recalibrated to 0.75 from the measured parse rates 0.833 / 0.800 / 0.767 (PREREG olm124 §0); olm124 and olm125 landed exactly on 0.750; olm127 fell at 0.667.
- **L1 / L2 / L3** — a verbatim value from the frozen output / a value recounted from rows / a reading by the main session (adoption is the PI's).
- **R4 / R5 / R6** — the house rules cited in the cards: summaries are claims and the frozen output is the evidence (R4); sets are built from predicates, not by hand (R5); an instrument is calibrated on positive controls before use (R6).
- **row keys** such as `b2_j07` — batch b, row j within the 60 rows of an arm.
