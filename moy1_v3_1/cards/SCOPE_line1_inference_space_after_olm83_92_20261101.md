## §0. 推論空間の探しの言葉(R5 = 機械の判別条件)

- **推論空間の候補** = 次の条件を満たすこと。
  - 位置 i の残差(層 32 か 48)を読む probe の AUC が、同じ位置の二つの基準の高い方を上回る。
    - 基準 1 = J-lens 層 48 の読み出し(O の集合 + 512 語の log p = 513 次元)。
    - 基準 2 = 直前 32 token の語の袋(単語 + 二語)。
  - 上回り方 = E = AUC(L)− max(AUC(J), AUC(W))の中央値が +0.05 以上で、5 % 点が 0 より上。
- 計器 = olm84 の `run_splits`(行を無作為に半分に分けて 200 回・学習の行で標準化した logistic・C 0.1・W は L1・他は L2)。olm84 から olm92 まで同じ。
- 偽の条件 = L32・L48 とも E の中央値 ≤ +0.01(各 PREREG の L3 の解ける条件)。
- 数に入れない札(除外):
  - olm83 = 統制 ✗ で読んでいない。
  - olm88 = 入口の関門 ✗ で読んでいない。
