## §5. 言えないこと

- 「指し」は、この組では「一つ目 / 二つ目の定義」と「選んだ名(P / Q)」が重なる(同じ cell の中で名の順は同じ)。順の指しか名の指しかは分けない。
- 「値」は直径の名の族(最初の token ` O` / ` He`)。名そのものの写しか、族の印かは分けない。
- 入れ替えは一つの位置・一つの層ずつ。まるごとで反転しても、その位置だけが持つとは言わない(同じ層のほかの位置も持ちうる)。反転しなくても、持っていないとは言わない(後の層で文の中から読み直されうる)。
- DAS の向きが行いを動かしても、それを model の「変数」とは言わない(部分空間の入れ替えは休眠の経路を起こしうる = 錯覚の見張りを置いた理由)。1 次元だけ。
- 合成の文・一つの model・V 型だけ。O 型(first / second)は使わない。
