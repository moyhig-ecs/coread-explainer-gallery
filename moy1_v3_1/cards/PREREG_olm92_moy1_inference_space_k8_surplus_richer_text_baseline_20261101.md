## §1. 行・位置・表現(R5)

- 行 = olm87 と olm90 の series の行で、出来事が 1 つ以上・負の候補が 1 つ以上の物(答えから始めた行も、述語が拾えば入る・olm89 と同じ)。
- 出来事・正・負は olm86 §1 と同じ述語。正 = j − k(k = 1・**8**・16・32)。負は行ごとに出来事の数 × 4(seed 9201・一つの乱数の列で olm87 → olm90 の名の順に引く)。
- 表現(位置 i ごと):
  - L32・L48 = 層 32・48 の残差。J = J-lens 層 48 の O の集合 + 512 語の log p(語 = olm91 の `vocab_pool` を使う行の上で・label を見ない)。W = 直前 32 token の単語 + 二語(L1)。ここまで olm89 と同じ式。
  - **W3** = W + 同じ 32 token の窓の三語の並び(L1)。
  - **P** = 位置の量(3 次元・L2): log(1 + i)(生成の頭からの位置)・log(1 + i 以前の最後の O の名の token からの距離)(無ければ i + 1)・log(1 + i までの O の名の続きの数)。i より後の印は読まない(自己検査)。生成の全体の長さは使わない(先の情報)。
  - **T** = 生成の中の直前 256 token(i を含む・prompt は入れない)の単語の袋(L1)。「段の話題」の代わりの固定の窓で、段落そのものではない。
  - **W+** = [W3, P, T] を並べた物(L1)。
  - **J+W+** = [J, W+] を並べた物(L1・記述だけ)。
  - 語彙 = 窓に出る行が 3 以上の単語・二語・三語(label を見ない)。
- 推定 = olm84 の `run_splits`(学習の行で標準化した logistic・C 0.1・行を無作為に半分に分けて 200 回)。罰則: W・W3・T・W+・J+W+ = L1・L32・L48・J・P = L2。足した表現の C は較正していない(W の C のまま)。

## §5. 言えないこと

- 「残る」でも「推論」の証明ではない。書式・四語より長い並び・256 token より前の話題・J の 513 次元の外の J-lens の分布を、残差が持つだけでも残りうる。
- 「消える」でも「残差は文の側の情報しか持たない」とは言わない。言えるのは、この計器で、上乗せが W+ を入れた max に収まる、まで。
  - 基準を三つの max にすると、max を取る側の上振れが二つの max より大きくなる。この札ではその大きさを分けない。
- T は固定の 256 token の窓で、段落ではない。P は三つの量で、位置の全部ではない。足した表現の C は較正していない。C1+ は、一つの特徴で決まる label を W+ が読めることだけを確かめる。
- olm87 の行の k = 8 の値は olm89 で見た(負の引き方は違う)。初めて見る行は olm90 だけ(Q4)。
- 一つの prompt(F5a-2)・一つの腕(natural)・OLMo-3 32B base の自分の生成。因果・中の状態は言わない。
