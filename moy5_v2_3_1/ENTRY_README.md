## 見方
- **一つの点 = 一本の答え**(jsonl の一行・rep の順)。塗りの青 = 答えの欄に cut / 青の輪 = 理由の欄にだけ cut / 小さな灰 = cut なし・床を述べた / 灰の輪 = どちらも無し。G 章(prf1 / prf3)は道の述語: 青の輪 + 点 = CHAIN / LAT_SYM、小さな灰 = END-only / FD_USE、× = 壊れた出力。I 章(OLMo)は床だけ(K は答えの欄 / 全体も)・破線の輪 = 空の行。章 J: 印 = 格の五つの欄(塗りの四角 = 判定・枠 = 記述・半分 = 較正・× = 言えない・破線 = 関門で止まった)・実線の目盛り = 凍結の線・破線の目盛り = 事後(判定でない)・斜線の枠 = 11-06 に足した。章 K: 太い枠 = 家が打つ束(束 ① = 依頼者 11-07)。
- **見出しの右の札の pill**(v2.1): 「札: …」= その状態が読む data の札。手で書いていない: DATA を包んで読みを記録し、engine が各状態の文(ja / en)と絵を一度実行して出す。状態 0〜22(10-28 の部分)に後の札が出たら検査が落ちる。
- **点の列の下の線 = 経路**: 実線 = API / 破線 = `claude -p` / 点線 = local MLX。帯の下に「経路 · effort · 札」。**別の札・別の経路・別の effort の点を線で結ばない**(札をまたいだ合算はしない)。
- 色の意味は一つ: 青 = apex(比例中項・Menaechmus)/ 橙 = 二次式(Descartes・**読み L3 の駅**)/ 灰 = 床(Pappus)。橙が data に付くのは、式を求めていない腕で頂点の形(symptoma)が出た mnw1 cone/Q1 の Fable 5 本(状態 21)だけ。prf1 / prf3 の二次式は PROOF の一文が求めた物で、橙にしない。

## 描き方の限界(README に書く約束)
- 切り口の面(v2.3)は半透明の一枚で、depth sort はしない(球と接触円はこの camera では面の奥 = 先に描き、放物線は面の上 = 後に描く。円錐の膜は面の手前の部分も奥に描かれる)。P_x を負へ大きく動かすと放物線と一緒に面も大きくなり、上端が枠の外へ出る(面の中の名は枠の中の空いた所に置き直す)。
- 立体の部品は class ごと・物ごとに奥から描くだけで、要素ごとの真の depth sort はしない。camera の既定の範囲(el 15〜35)の外へ回すと前後が逆に見えることがある(el は 3〜82 に clamp)。平面の状態は回らない。
- 答えの板は固定の斜投影(字を水平に保つため)で、作図の板・駅・梯子の camera とは別。
- 状態 0 / 7 の円錐・Dandelin 球の重ね描き(v2.2)は、凍結の座標 A・G・E・F・C と r から計算した作図。円錐は凍結の J の高さで切って描き、P_x を動かすと切り口の放物線と倒す点線だけが動く(P_x を負へ大きく動かすと、v2.1 の P_y と同じく枠の外へ出る)。前後の描き分けは半透明の重ねで、depth sort はしない。
- 状態 0 / 7 で P_x を動かした絵は、問いの文の定義から描画のために計算した物(D・H も同じ)。data ではなく、値は出さない。凍結の P_x では計算した K・P_y・J が問いの座標と 6.1e-4 以内(assert < 1e-3)。
