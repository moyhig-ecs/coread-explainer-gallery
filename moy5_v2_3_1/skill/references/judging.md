# 審査(冷間・作り手と違う族)

## 組み方
- 作品は札の名(entry_P / Q / R …)だけで呼ぶ。作り手と札の対応は封(SEALED_*)にして審査者に見せない。
- 各札を **作り手と違う族の model** の二人が見る(例: Sonnet が作った札 → Opus と Fable)。互いの判定を見せない。
- 審査者が読むのは: 判定基準の file・BRIEF・稿の該当節・data の照合表・その札の撮影 PNG と CLAIMS / NOTES / README / 台本だけ。

## 物差し(基準の file に書く)
- **E1 editor を通るか**(通る / 直せば通る / 通らない): 忠実さ(事実の文を 5 つ以上照合)・主張の置き場(機構・正誤・潰した値を沈み・eligible でない帯の null を「無い」・語の場から考えを言う・陽性統制と門の混同・計器の限定の欠落・一例から「だけ」)・図として(札・凡例・目盛・出所・限定が撮影に写る・色の意味が一つ)。
- **E2 動画の作者が図解できるか**(できる / 手を入れれば / できない): 1920 × 1080 と台本だけで 1〜2 分・最初の 10 秒・字の大きさ。
- **E4 「この計器だから、この読みが出た」**(言えている / 一部 / 言えていない): 陽性統制・門・帯で読みが入れ替わること・判と保留が、稿の言い方のまま撮影の上で鎖になっているか。
- **E3(参考)**: 層を上ると場が変わること・「model の中の意味の地図」に見えないこと。
- 「図の上」= 撮影の PNG に写っているものだけ。

## 返させるもの
札ごとに E1・E2・E4(判定・理由・照合の結果・引用・確信度)→ 比べ → editor が突く所・動画の作者が困る所 → 迷った点と物差しへの指摘。合算しない(審査者の一致率で物差しを較正する)。

雛形: この束の `templates/JUDGE_criteria_template.md`。
